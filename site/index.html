Baseline Review

A live review checklist for Excel workpapers, with last year's review notes built in.

Download add-in file Download demo workbook
  1. Tap Download add-in file above. It saves manifest.xml to Downloads.
  2. Open Excel on the web (office.com) and open any workbook.
  3. Home → Add-ins → More Add-ins → My Add-ins → Upload My Add-in, then pick manifest.xml.
  4. Click Review on the Home tab.
  5. Want to see it in action? Open the demo workbook and follow its Start here tab.
